Interactive lessons for making games in Picotron. Every lesson runs live beside its code, and every bit of code is yours to copy into Picotron and tinker with.

Beginner basics

Start here if you've never programmed. Lua, the game loop, input, sprites, maps and sound.

  1. The game loop Picotron calls your functions over and over; that's what makes a game move.
  2. Numbers, variables and repeating Doing arithmetic, keeping score, a dash of randomness, and doing something many times.
  3. Moving with btn() Read the buttons every frame and steer a player around the screen.
  4. Making decisions Ask questions about what's happening in the game, and let the answers decide what it does next.
  5. Lists Keep many things under one name, and loop over them all.
