welcome.txt

Demotron

Little interactive lessons for making games in Picotron. Every lesson runs live, right beside its code, and every bit of code is yours to copy into Picotron and break, fix and make your own.

new here? start with Getting started →

beginner_basics/

Start here if you've never programmed. Lua, the game loop, input, sprites, maps and sound.

  1. 00Getting startedInstall Picotron, find our way around it, and run, save and fix a first program.
  2. 01Files and the terminalPicotron's own drive, and the terminal commands for finding, making, saving and loading things on it.
  3. 02The game loopThe three functions Picotron calls to run a game, what belongs in each, and the order they paint in.
  4. 03Numbers, variables and repeatingArithmetic, variables, integers and floats, remainders, loops and random numbers.
  5. 04Moving with btn()Reading the buttons with btn and btnp, and steering a player around the screen.
  6. 05Making decisionsComparisons, keeping things on screen, else and elseif, combining questions, and a ball that bounces.
  7. 06ListsLists, looping over them, adding and removing items, all(), and a starfield.
  8. 07ObjectsTables with named fields, lists of objects, functions that build them, methods, and removing objects.
  9. 08Functions and filesDefining functions, parameters, return values, local variables, functions as values, and splitting a game across files.
  10. 09SpritesThe sprite editor, drawing a character, putting it on screen with spr, flipping, a walking animation and transparency.
  11. 10MapsThe map editor, drawing a level with map, tiles and pixels, walls with sprite flags, and a camera that follows the player.
